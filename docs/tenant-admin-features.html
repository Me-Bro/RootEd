🔑 The permission bundle

Defined once in apps/api/src/models/Role.js — tenant_admin gets literally every entry in the PERMISSIONS list, no filtering:

attendance:readattendance:write grades:readgrades:write students:readstudents:write staff:readstaff:write leave:readleave:writeleave:approve expense:readexpense:writeexpense:approve fees:readfees:writefees:collect inventory:readinventory:write payroll:readpayroll:write roles:readroles:write audit:read tenant:admin

👥 Where tenant_admin sits

  • super_admin (system role, above all tenants) → sees every school, can impersonate, suspend, bill
  • tenant_admin (you are here) → everything below, but locked to one school
  • principal → read-everything + approve leave/expense, no write access to records
  • teacher → attendance + grades write, students read-only, own leave requests
  • accountant → fees + expense + payroll read/write, nothing academic
  • librarian → inventory read/write only

Academic

full access

Everything about running classes: years, students, attendance, grades, timetable, report cards.

📅 Academic Years & Terms

  • Create/edit academic years — e.g. "2025-26" with start/end dates, mark one active
  • Create terms inside a year — e.g. "Term 1" (Apr–Sep) — grades and fee structures are scoped to a term/year

🧑‍🎓 Students students:read/write

  • Add Student — admission no, name, section, DOB, gender, parent contacts
  • Import CSV — bulk-add students from a spreadsheet
  • Edit / withdraw / graduate a student's status
  • List filterable by section, searchable by admission no / name

✅ Attendance attendance:read/write

  • Mark attendance per section per day — present / absent / late / excused
  • View attendance history for a student or a whole section

📝 Grades grades:read/write

  • Enter scores per student, per subject, per term (0–100, auto letter-grade A–F)
  • View a student's grade history across terms

🗓️ Timetable

  • Build weekly class/section timetables — subject + teacher + period slot

📄 Report Cards

  • Generate PDF report cards per student per term — built async by the reportCard.worker.js BullMQ worker, not inline (so a large batch doesn't block the request)
🧑‍💼

Staff

full access

Staff directory, leave approval chain, salary/payroll.

📇 Staff Directory staff:read/write

  • Add/edit staff profile — designation, department, joining date, qualifications, documents
  • Sensitive fields (government ID, bank account) are AES-256-GCM encrypted at rest, per-tenant key — you see them decrypted, they're never stored in plaintext

🌴 Leave Requests leave:read/writeleave:approve

  • Staff submit leave requests; you (or principal) approve/reject
  • Each request carries its own approvalChain array — sequential approvers only, no parallel steps
  • Left too long → auto-escalates to next approver via a delayed BullMQ job (expenseEscalation.worker.js pattern, same idea for leave)

💰 Salary payroll:read/write

  • Define Salary Structures — components like Basic, HRA (fixed amount or % of basic)
  • Generate monthly Salary Slips per staff member — gross/deductions/net pay, PDF export
💸

Expense

full access

Track spending against cost centers, with an approval chain before payout.

Expense Entries expense:read/writeexpense:approve

  • Submit an expense — title, category, amount, vendor, invoice date, attach receipt, tag a cost center
  • Approve/reject/mark paid — same embedded approvalChain pattern as leave
  • Cost Centers — group spending (e.g. "Academics", "Facilities") with a budget ceiling
Bug in the permission model: principal's filter accidentally includes tenant:admin, which routes them into the "admin escalation" bucket instead of the normal approver bucket in expense.service.js. Doesn't affect tenant_admin directly, but worth knowing if you're testing the principal flow.

Fee

full accessknown bug

Fee structures, per-student assignments, payment collection.

Fee Structures & Assignments fees:read/write

  • Define a Fee Structure — components like Tuition, Activity fee, tied to an academic year
  • Assign it to a student → creates a payable amount with a due date, tracks unpaid/partial/paid/waived
  • Discounts — apply a reduction with a reason

Payments fees:collect

  • Collect a payment — cash/card/UPI/bank transfer/cheque, generates a receipt number + PDF
  • Razorpay integration for online payment + webhook verification
⚠️ Known bug (from CLAUDE.md): POST /fee/payments/verify hardcodes amount: 0 instead of using the Razorpay-verified charged amount. Don't trust the online-payment verify path for real amounts yet.

  • View current plan (e.g. "pro"), status (active/suspended)
  • Payment history for the subscription itself (via Razorpay)

Inventory

full access

Two kinds of items tracked differently: consumables (stock count) and fixed assets (depreciation).

Items inventory:read/write

  • Consumables — quantity + reorder level (markers, notebooks, lab chemicals) — auto-flagged when stock dips below reorder level via inventoryOverdue.worker.js
  • Fixed Assets — projectors, computers, furniture — tracks purchase date, depreciation method (SLM/WDV), current value, condition
  • Stock Movements — log of every quantity change (received, issued, adjusted)

Purchase Requisitions expense:approve

  • Staff request more stock of an item → you approve → can link to an actual Expense Entry once purchased
🔐

Roles & Permissions

full access

Only tenant_admin (via roles:write) can create custom roles or change who has what.

  • 5 templates pre-seeded per tenant: tenant_admin, principal, teacher, accountant, librarian
  • Can create custom roles with any subset of the 14 permission strings
  • Assign a role to a staff member's TenantMembership — takes effect within 60s (Redis permission cache TTL)
