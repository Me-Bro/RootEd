Landing page — approved

RootEd has no public-facing page today — the domain resolves straight to /login. This replaces the earlier 8-concept exploration with two designs, now approved: desktop keeps the Product-led content direction, mobile was rebuilt from scratch. Every fact used is real — pulled from ruralrootcloud.com and this repo's own README.md — no fabricated stats, testimonials, or customer logos.

✅ Approved — both mockups below are signed off. Next step when you're ready to build: wire desktop.html/mobile.html into a real LandingPage.jsx route, source real product screenshots to replace the labelled placeholder, and build the signup page the "Start free trial" CTA hands off to (see "Not in this batch" below).
What changed from the exploration: no individual founder bios/quotes/avatars, no LinkedIn link — trust now comes from the product's own security substance and Rural Root Cloud as a company, not two named people. Mobile is a full redesign (bolder type, full-bleed alternating bands, editorial cards, a connected process stepper), not a refinement of the old concepts. Both now carry a small recurring brand motif — a root-branch line texture behind the hero and mission-statement band, the same visual language as concept 1 in the logo exploration. Round 4: the audience is broadened, honestly — RootEd genuinely supports schools, colleges, and coaching/tuition centers (5 real org types, packages/shared/src/constants), so the hero and multi-tenant copy now say so, without claiming a parent/student login that doesn't exist. Also fixed a real contrast bug in mobile (inherited light text on a white background — invisible) and a WCAG failure in the brand gradient itself (white text at ~2:1 against the cyan end, now ~5:1). Full reasoning in PLAN.md.
