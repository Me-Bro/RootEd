Security

Staff bank details and student records, protected on purpose

Here is what protects them, in plain words first and technical detail second.

01

One school can never see another's data

Every database query is checked against your school before it runs. If a bug tried to read someone else's rows, it would fail, not quietly return them.

tenantId enforced by a Mongoose plugin on every tenant-owned model
02

Bank accounts, IDs and salaries are encrypted

Each school has its own encryption key, so there is no single key that opens everyone's data.

AES-256-GCM · per-tenant key via HKDF-SHA256
03

You can always see who changed what

Every change to a sensitive record is saved as a before-and-after entry that nobody can edit afterwards.

Immutable AuditLog, written asynchronously

FAQ

Questions schools ask first

Is RootEd really free?

Yes. Every core module is free, with unlimited staff and students, no trial and no expiry. Dedicated email, WhatsApp, SMS and your own payment gateway are paid add-ons.

Is there a mobile app?

Yes, an Android app is on Google Play. The web app also works in a phone browser, with the same login and data.

Does it work in Hindi?

Yes. Choose English, Hindi, or a combined Hindi / English view.

Who can see staff salaries and bank details?

Only roles you give that permission. A librarian cannot see payroll and a teacher cannot see budgets. Those fields are also encrypted at rest.

Can students log in?

Yes. A student login opens a personal view of their own attendance, published grades and report cards, and nothing else.

Do you support colleges and study centres?

Yes. Schools, colleges, coaching and tuition centres, and study centres each get a setup that fits, on the same platform.
