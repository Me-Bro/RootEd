scroll for the rest · no page numbers
＋
  1. Class cards. Tap a grade to reveal its 4 sections — replaces the 40-option native select entirely.
  2. Section chips. One more tap picks the section; the roster loads below in place.
  3. Infinite scroll. Roster loads 20 at a time on scroll — the "page 1 of 50" pager disappears.
  4. 🔍 Search stays available in the header for the case where the name is already known — this doesn't replace drill-down, it's the fast path alongside it.
Why Mock 2 is the approved one: the 40-option section select and the 50-page pager are the two most-cited pain points for this screen in the plan (§2, P8/P9). Drill-down plus infinite scroll fixes both with components that already exist elsewhere in the app (useClassSections already returns classes with nested sections — it's the data source, just presented as cards instead of a flat list).

2 · API contracts — every one of these already exists

1. Load classes + sections existing hook, reused
GET /academic/classes?includeSections=true // 200 — already used by useClassSections; each class carries its sections nested [{ "_id":"…", "name":"Grade 5", "gradeLevel":5, "sections":[{ "_id":"…", "name":"A" }, …] }]
2. Load a section's roster, paged for infinite scroll
GET /academic/students?sectionId={id}&page=1&limit=20 // 200 — unchanged shape; "infinite scroll" just means the client calls page+1 // automatically near the bottom instead of showing Prev/Next buttons { "students":[…], "total":21, "page":1, "pages":2 }
3. Search (unchanged) / Create / Import
GET /academic/students?search={q}&limit=20 // existing debounced search, still available from the header icon POST /academic/students // unchanged — admissionNo, firstName, lastName, sectionId, dateOfBirth, gender POST /academic/students/import // unchanged — CSV multipart, same result modal

6 · Definition of done

  • Class cards replace the 40-option native select entirely
  • Infinite scroll replaces the "Page X of 50" pager; no page-number UI remains
  • Search from the header bypasses drill-down and shows a flat result list
  • Last-used section is remembered per device and pre-opened next visit
  • Add Student and Import CSV behave identically to today
  • Verified against the real 1000-student, 40-section dataset
