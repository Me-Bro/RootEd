  1. Live class average updates as marks are entered — feedback the OS-keyboard version never gave.
  2. Docked keypad. Custom, not the OS keyboard — the roster above never gets covered.
  3. AB = absent for this assessment; auto-advances to the next unmarked row on submit.
Why Mock 2 is approved: this exact pattern was already validated in the earlier exploration (concept 2, ★ recommended) — the docked keypad is the single highest-value fix for this screen because the OS keyboard problem is universal across every phone, not a judgment call. This spec formalizes it with real API contracts and a Definition of Done.

2 · API contracts — every one of these already exists

Unchanged endpoints — only the input UI changes
GET /academic/grades?sectionId=&termId=&subjectId=&assessmentType= POST /academic/grades {{ "grades":[{{ "studentId","sectionId","subjectId","termId","academicYearId","assessmentType","score" }}] }} GET /academic/grades/lock?... // unchanged — locked assessments still block Save the same way
Known bug carried over, not fixed by this spec: GradesPage.jsx calls GET /academic/terms without ?yearId — with 3 seeded years that renders 6 near-identical term options. Fix is one line (?yearId=activeYearId) but is out of scope for this UI-only spec; flagging so it isn't missed.

3 · State & logic

const [focusedId, setFocusedId] = useState(firstUnmarkedStudentId); const [draft, setDraft] = useState(''); // the digits typed on the docked keypad, not yet committed function keypadPress(key) { if (key === '⌫') return setDraft(d => d.slice(0, -1)); if (key === 'AB') return commitAndAdvance(null); // absent for this assessment const next = draft + key; if (Number(next) <= 100) setDraft(next); } function commitAndAdvance(score) { setScoreMap(m => ({{ ...m, [focusedId]: score }})); setDraft(''); setFocusedId(nextUnmarkedId(focusedId)); // roster order, wraps to the guard sheet when all are marked } const liveAverage = Object.values(scoreMap).filter(Boolean).reduce(avg, 0);

6 · Definition of done

  • Docked custom keypad replaces the OS number keyboard entirely
  • Live class average updates as each mark is entered
  • AB marks a student absent for this one assessment and auto-advances
  • Roster list never scrolls out of view while the keypad is open
  • Lock banner behaves identically to today's desktop lock state
